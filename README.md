# Termo-Game-em-Python
Esse jogo foi desenvolvido com intuito de obter nota semestral na matéria de Python

Cores Jogo termo 
                                                     
quando a palavra não terá nada haver com o tema
                Fonte      Fundo

              Fonte         Fundo
Vermelho   	\033[1;31m	\033[1;41m

        Fonte         Fundo
